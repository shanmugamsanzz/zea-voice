# Caller-name intake and evidenced summary follow-up

Each telephone call loads the saved caller name under the persisted call's tenant/workspace and inbound From/outbound To. This lookup also runs when conversation continuity is disabled or unavailable, unless the name was already loaded. Browser tests do not access real contact names. Lookup failure suppresses proactive name collection rather than pretending a known name is missing.

When update_contact is attached, every universal turn gets known-name and optional-question-already-asked state independently of retained turns. The LLM asks once at a natural early pause if missing, never forces, and skips emergencies, transfers, refusals and goodbye. Structured callerNameAsked metadata updates the per-call flag; tool-result replies support the same metadata. Invalid/suppressed execution announcements do not count as a delivered name question. Patient-name intake remains separate. Existing update_contact evidence/consent validation and report-name lookup are unchanged. Name-question recognition remains a model responsibility, so test with live speech before rollout.

New summaries default follow_up_required to false. A true flag requires a concrete caller-requested future contact or agreed pending next action, a reason, and follow_up_evidence with basis and an exact caller quote. The normalizer checks that quote against caller/user transcript entries; agent-only statements, unsupported reasons or missing evidence cannot set the flag. The prompt also requires accounting for later completion/cancellation/refusal. Semantic interpretation of agreement remains the model responsibility; quote matching alone does not prove agreement. Existing stored summaries are not rewritten. No migration or automatic callback is introduced.

Tests: verify-name-and-follow-up.js, summary output/processor/live-flow, universal response contract and existing runtime/RAG regressions. UAT: returning unnamed caller, known caller, refusal and trimmed history, relative-patient booking, no-agreement summary, explicit callback and later cancellation.
