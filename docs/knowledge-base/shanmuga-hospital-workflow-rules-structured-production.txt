SHANMUGA HOSPITAL - APPROVED WORKFLOW AND ACTION RULES
FORMAT VERSION: 4
LANGUAGE: Tamil, Tanglish and English
USAGE: Inbound and Outbound

RULE: emergency_support
SITUATION: The caller describes severe chest pain, severe breathing difficulty, unconsciousness, stroke symptoms, uncontrolled bleeding or another urgent medical emergency.
EXAMPLE: நெஞ்சு வலி ரொம்ப அதிகமா இருக்கு | மூச்சு விட முடியல | மயங்கி விழுந்துட்டாங்க | ரத்தம் நிற்காம வருது | severe chest pain | cannot breathe | unconscious | heavy bleeding
MATCH_MODE: any_phrase
RESPONSE_MODE: exact
PRIORITY: 100
RESPONSE: இது urgent medical situationஆ இருக்கலாம். உடனே அருகிலுள்ள emergency medical help எடுத்துக்கோங்க.

RESPONSE_MODE: instruction
PRIORITY: 100
ACTION: end_call
RESPONSE: Acknowledge the caller politely, use the configured closing message and end the call only after the closing audio completes.

RULE: create_appointment
SITUATION: The caller explicitly requests to book an appointment for an already selected approved package.
EXAMPLE: appointment book பண்ணுங்க | booking பண்ணலாம் | இந்த package book பண்ணுங்க | book an appointment | reserve this package
MATCH_MODE: any_phrase
RESPONSE_MODE: instruction
PRIORITY: 96
ACTION: create_appointment
REQUIRES_CATALOG_ITEM: true
BLOCKED_RESPONSE: Appointment book பண்ணலாம். முதல்ல எந்த approved Package வேணும்னு சொல்லுங்க.
RESPONSE: Preserve the selected Catalog item. Collect only the missing UI-configured fields in their configured order. Read the details back once, request final confirmation, and execute the action only after confirmation. Never claim success without a verified successful tool result.
